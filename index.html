日本について

日本は伝統と文化を大切にする国です。しかし若者の人口は年々減っていき、フィリピンの人たちの協力が必要です。日本語を学ぶことで、多くのフィリピンの人たちが日本に興味を持ち、日本で活躍してもらいたいと思います。

🇵🇭

フィリピンについて

フィリピンは、平均年齢が２４歳と若い国です。人々は、明るくフレンドリーな性格や高いホスピタリティ精神、家族を最優先にする深い家族愛に溢れています。

自然も豊かで、フルーツやマグロなどの魚もたくさん日本に輸入されています。

このアプリでお互いの国の言葉を勉強して、多くの人たちがお互いの国に関心を持ち、お互いの素晴らしい国を訪れることを願います。

プロフィール設定

あなたの言語バックグラウンドと学びたい言語を登録してください。

Supabase 連携設定

無料の Supabase データベースと接続してリアルタイム接続を有効化します。

Supabaseのテーブル構築手順:

SupabaseのSQL Editorで以下のテーブルを作成してください:

CREATE TABLE profiles (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  native_lang TEXT NOT NULL,
  learning_lang TEXT NOT NULL,
  bio TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
