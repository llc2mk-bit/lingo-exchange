This platform was created to deepen cultural and linguistic exchange between Japanese speakers and Visayan speakers.

Japan is a nation that cherishes tradition and culture. However, with its youth population declining each year, the cooperation of people from the Philippines is essential. The Philippines is a vibrant young country with an average age of just 24. Its people are known for their bright, friendly nature, high spirit of hospitality, and deep love for family. The country is blessed with rich nature, exporting delicious tropical fruits and fresh tuna to Japan.

Through this app, we hope users learn each other's languages, foster mutual interest, and visit each other's beautiful countries.

プロフィール編集

Supabase 連携 & DBスキーマ設定

無料のSupabaseプロジェクトのURLとAnon Keyを設定すると、複数端末や他ユーザーとのリアルタイム通信・全データ同期が可能になります。 

-- 1. プロフィールテーブル作成
CREATE TABLE IF NOT EXISTS profiles (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  native_lang TEXT NOT NULL,
  target_lang TEXT NOT NULL,
  avatar_url TEXT,
  bio TEXT,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- 2. メッセージ送信履歴テーブル作成
CREATE TABLE IF NOT EXISTS messages (
  id BIGSERIAL PRIMARY KEY,
  sender_id TEXT NOT NULL,
  receiver_id TEXT NOT NULL,
  text TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- 3. RLS（行セキュリティ）無効化、または全許可（デモ用）
ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE messages ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read/write profiles" ON profiles FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Allow public read/write messages" ON messages FOR ALL USING (true) WITH CHECK (true);

-- 4. 送受信履歴取得用インデックス
CREATE INDEX IF NOT EXISTS idx_messages_conversation ON messages (sender_id, receiver_id);
